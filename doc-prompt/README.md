# 다큐 조립대 (과학 다큐 프롬프트 생성기)

과학 주제와 설명 기법, 구성, 톤, 내레이션, 화면 연출 요소(182개, 9개 분류)를 고르고 강도를 정하면,
애니메이션 과학 해설 영상의 장면별 대본을 받아낼 프롬프트를 만들어주는 정적 웹페이지입니다.

결과 형식은 JSON(영상 코딩용), 장면표, 내레이션 대본 중에서 고를 수 있습니다.
JSON은 장면마다 길이, 내레이션, 화면 글자, 도형과 색으로 쓴 화면 설명, 움직임, 전환을 담습니다.

- `index.html`: 브라우저에서 바로 여는 완성본
- `app.html`: 같은 내용의 본문 (Artifact 게시용)
