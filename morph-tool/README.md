# 이미지 모핑 공방

이미지 여러 장을 넣으면 순서대로 모양이 녹아 이어지는 mp4를 만드는 단일 HTML 도구. 설치 없이 크롬/엣지에서 `dist/모핑공방.html`을 열면 된다 (인터넷 없어도 동작).

- 배경 찾기: 테두리 색에서 번져 나가는 영역 채우기 → 남은 가장 큰 덩어리를 물체로 봄
- 윤곽 대응: 외곽선을 N개 점으로 나누고, 시작점을 돌려 모양이 가장 잘 겹치는 짝을 고름
- 변형: 윤곽점 + 화면 가장자리 점으로 들로네 삼각분할, 삼각형별 아핀 워프 후 교차 합성
- 내보내기: WebCodecs + mp4-muxer(내장, MIT)로 프레임 단위 인코딩, 없으면 MediaRecorder 실시간 녹화

빌드: `python3 build.py` (src/morph.html + samples/ + vendor/ → dist/)
