# 웃음 조립대 (유머 프롬프트 생성기)

웃음 코드, 형식, 말투, 소재 같은 요소를 고르고 강도(1~5)를 정하면,
챗지피티 같은 채팅에 붙여넣을 유머 글 작성 프롬프트를 만들어주는 정적 웹페이지입니다. 서버나 API가 필요 없습니다.

챗지피티 유머가 어색해지는 흔한 이유(펀치라인 설명, 이모지와 ㅋㅋ, 교훈 마무리, 번역투 농담)를 막는 원칙이 항상 들어가고,
웃겼던 글을 예시로 붙여넣으면 내용은 빼고 말투와 호흡만 따라 하도록 지시합니다.

- `index.html`: 브라우저에서 바로 여는 완성본
- `app.html`: 같은 내용의 본문 (Artifact 게시용, 문서 뼈대 없음)

선택 상태는 브라우저 localStorage에 저장됩니다.
