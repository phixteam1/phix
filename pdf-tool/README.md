# PDF 정리함

알PDF '페이지 편집' 화면 기능만 모은 가벼운 사무용 PDF 도구. `dist/PDF정리함.html` 하나를 크롬/엣지로 더블클릭해서 쓴다. 설치·인터넷 필요 없고, 파일은 브라우저 밖으로 안 나간다.

기능: 여러 PDF·이미지 병합, 썸네일 드래그로 순서 변경, 삭제, 90° 회전, 파일/빈 페이지 삽입, 복제, 선택 추출, 분할(1쪽씩·N쪽씩·범위·원본 파일별, ZIP), 쪽번호, 워터마크, A4 등 크기 맞추기, 크게 보기, 되돌리기, 저장 위치 선택.

## 빌드
`python3 build.py` → `src/` + `vendor/`(pdf.js 3.11.174, pdf-lib 1.17.1, 한국어 CMap)를 한 파일로 합침.
