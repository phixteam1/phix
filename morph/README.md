# 모핑 영상: 사자 → 바나나 → 비행기

코드로 그린 도형이 부드럽게 변하는 영상을 만든다.

```bash
pip install numpy pillow imageio-ffmpeg
python3 morph/morph.py      # morph/out/morph.mp4
```

어떻게 동작하나:
- 세 그림 모두 같은 개수(8개)의 도형 조각으로 그린다 (예: 사자 갈기 ↔ 바나나 몸통 ↔ 비행기 동체).
- 조각마다 외곽선을 둘레 길이 기준 260개 점으로 다시 샘플링하고, 시작점을 맞춘 뒤 점끼리 보간한다.
- 색, 배경 그라데이션도 같이 보간하고, 조각마다 시차를 줘서 더 자연스럽게 보이게 했다.
